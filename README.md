# Lašu mednieks

Spēles mērķis: Savākt Pēc iespējas vairāk lašu!

## Mapju struktūra un atvēršana
- `index.html` — galvenā spēles sākumlapa
- `atteli/` — paša zīmēts PNG varonis
- `skanas/` — spēles skaņas efekts

Atvēršana: atver `index.html` interneta pārlūkā no projekta mapes.

## Dizaina izvēles un pārbaude
- Dizaina izvēle un pārbaude
- Vizuālais noformējums: Tumši zils fons ar gaišu tekstu, kas rada kosmisku noskaņu un nodrošina labu kontrastu. Spēles laukums ir centrēts un pielāgojas arī šaurākam pārlūka logam.
- Noteikumi un gaita: Spēlē ir laukums, kur pēc izvēlētā režīma uz mirkli parādās zivis, uz kurām spēlētājam ir jāuzklikšķina. Jo vairāk lašu spēlētājs savāc, jo labāks ir rezultāts.
- Pārbaudes un funkcionalitāte: Ir pārbaudīts, ka attēli, skaņas un punktu skaitītājs (piemēram, 3 klikšķi = 3 punkti) darbojas pareizi.
- Sadarbība un uzlabojumi: Pēc klasesbiedra atsauksmes tika veikts uzlabojums – palielināts pogas fonta izmērs, lai to būtu ērtāk pamanīt.
